# Vercel deployment checklist

1. Upload this project's contents to the root of a GitHub repository.
2. Import the repository into Vercel.
3. Select Next.js; use `npm run build` as the build command.
4. Add `NEXT_PUBLIC_CONTACT_EMAIL` with your actual business email if you want email enquiries enabled.
5. Deploy and test on mobile and desktop.
6. Before commercial sales, integrate payments, order storage, shipping, stock, transactional email and required legal pages.

The current bag is an enquiry-only prototype. It does not process payments or persist orders.
